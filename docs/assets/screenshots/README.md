# Application screenshots

The application interface artifact is generated by the real Chromium browser suite in GitHub Actions. The tests use the synthetic PostgreSQL fixtures and capture the UI after representative operations. Each PNG has a JSON manifest with its screen, viewport and source commit.

The desktop set measures 1440 × 1000. Selected mobile views measure 390 × 844. The same suite checks navigation and page overflow at widths of 1440, 1280, 1024, 768, 390 and 375 pixels.

To reproduce the captures locally against the disposable Playwright application server:

```sh
LAB_SCREENSHOTS_DIR=docs/assets/screenshots LAB_SCREENSHOT_REVISION="$(git rev-parse HEAD)" npm run test:e2e
```
